    Design system

    Pulled from the logo

    Two colors carry the brand: the green from the recycle mark inside the O, and the graphite/chrome of the wordmark. Everything else is a neutral tuned slightly toward that green.

    Color

    Type scale

    Display — hero headline
    H1 — page title
    H2 — section heading
    H3 — card and block heading

    Lede — the introductory line under a heading, set wider and lighter.

    Body — the default paragraph. Set at 16px with a 1.55 line height so long fitment lists and warranty copy stay readable on a phone in the yard.

    Eyebrow — uppercase label

    Small — stock numbers, mileage, and other supporting data.

    Live store serves Archivo (headings) over Assistant (body) from Shopify's own font CDN. This preview falls back to the system stack — the shapes shift slightly, the hierarchy doesn't.

    Status badges
